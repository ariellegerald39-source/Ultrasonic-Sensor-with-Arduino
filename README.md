The assignment demonstrates hardware integration, circuit wiring, and programming using an Arduino and an **HC-SR04 ultrasonic distance sensor** from the Elegoo Uno starter kit.
## Hardware & Equipment
* **Microcontroller:** Arduino Uno (Elegoo Kit)
* **Sensor:** HC-SR04 Ultrasonic Distance Sensor (Trig, Echo, VCC, GND pins)
* **Breadboard & Jumper Wires**
* **Test Objects:** Three distinct small objects utilized for distance profiling during demonstration.
